# viebBook downloads

Official public installers and signed update metadata for viebBook. Application source code and user libraries are not stored here.

[Download the latest installers](https://github.com/the-shoemaker/viebBook-updates/releases)

Mac updates use Sparkle with Ed25519 archive signatures. Android verifies the download checksum, package version and installed signing certificate before opening Android's installer. Updates preserve books and answers when the installed signing certificate matches.
